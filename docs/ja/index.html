AITextBlur プライバシーポリシー

最終更新日: 2026年6月12日

1. 概要

AITextBlurは、Google ML Kitを搭載した画像編集ツールであり、AIによるテキスト検出と写真のピクセル化ぼかし機能を提供します。本プライバシーポリシーでは、Google Playポリシー、GDPR、CCPA、日本のAPPI、韓国のPIPAに準拠し、ユーザーデータの収集、使用、保存方法について説明します。

2. 収集するデータとその使用方法

2.1 ローカルフォト（ローカルのみで処理、クラウドアップロードなし）

デバイスのギャラリーまたは他のアプリから共有された画像にアクセスし、テキスト検出、モザイク編集、および編集済み画像の保存のみに使用します。

すべての画像処理はデバイス上で100%オフラインで実行されます。元の画像は当社のサーバーにアップロードされることはありません。画像はデバイスのローカルキャッシュまたはギャラリーにのみ保存されます。アプリをアンインストールすると、すべてのキャッシュデータは消去されます。当社は元の写真にアクセスすることはできません。

2.2 匿名デバイス情報（広告およびクラッシュ分析）

無料ユーザー限定：匿名デバイスID、デバイスモデル、OSバージョン、クラッシュログを収集し、バナー広告の表示とアプリ安定性の向上に使用します。個人を特定できる情報は追跡されません。

有料プロユーザーは、広告関連のデータ収集がすべて無効になります。

2.3 オフラインGoogle ML Kitテキスト認識

テキスト検出は、Google ML Kitを介してデバイス上でオフラインで処理されます。検出されたテキストデータはメモリ上に一時的に存在し、編集後に破棄されます。テキストコンテンツは当社のサーバーに送信されることはありません。

2.4 決済データ（決済情報は一切収集しません）

すべてのアプリ内購入は、Google Play Billingを介して独占的に処理されます。当社はクレジットカード情報、請求情報、Googleアカウントの決済詳細を収集、保存、またはアクセスすることはありません。すべての決済トランザクションはGoogleのプライバシー条項に準拠しています。

2.5 ローカルトライアルタイマーデータ

初回アプリ起動時のタイムスタンプは、14日間のフル機能トライアル期間を計算するためにローカルにのみ保存され、クラウド同期は行われません。

3. 広告に関する声明

無料トライアル版および期限切れの無料版では、AdMobバナー広告が表示されます。広告配信のために匿名デバイス識別子が収集されます。EU/英国/トルコのユーザーは、個人設定広告をオプトアウトすることができます。

一括購入のプロ版は、すべての広告を永久に削除し、すべての広告データ収集を停止します。

4. データ共有

当社は、以下を除き、第三者に対して個人データを販売、貸与、または共有することはありません。

  • 公式Google SDK（ML Kit、AdMob、Google Billing）：SDK機能に必要な匿名デバイスデータのみで、Googleのプライバシーポリシーに準拠しています。
  • 公式司法機関からの法的強制要請。

5. ユーザーの権利

  • データの削除：アプリをアンインストールすることで、すべてのローカルキャッシュとトライアル記録を消去できます。ギャラリーの写真は完全にユーザーが管理します。
  • 権限の取り消し：システム設定でストレージ/ギャラリーの権限を無効にすることで、写真のインポートとエクスポートを停止できます。
  • EU/カリフォルニア在住者：サポートメールを介して、すべての匿名使用ログのアクセスまたは削除を請求できます。

6. 児童向けポリシー

本アプリは13歳以上のユーザーを対象としています。当社は13歳未満の児童から故意にデータを収集することはありません。

7. ポリシーの更新

当社は本ポリシーを更新する場合があります。更新内容はアプリ内で通知されます。アプリの継続的な使用は、改訂されたポリシーへの同意を意味します。
